# ESuite 1.0.6

- Developer Tools and everyday utilities dock below the live page on phones and beside it on wider screens. Drag the divider to change the split. The toolbar or F12 opens Developer Tools.
- The JavaScript console runs expressions and scripts in the current page, shows results and errors, and distinguishes warnings, errors, and other messages.
- Inspect and edit selected elements, list source resources, view resource and navigation timings, and examine the viewport, page semantics, security context, cookies, and storage metadata.
- Android WebView uses the site's mobile viewport declaration, supports pinch zoom, and shows the committed page as soon as WebView can render it.
- A branded startup screen, Inter typography, refined light and dark palettes, and updated navigation and browser controls give the app a consistent visual style.

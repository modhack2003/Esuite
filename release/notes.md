# ESuite 1.0.9

- Activity now has a Site Map and source-aware History. Open an in-memory Browser Network snapshot in a matching saved site and see WebView callbacks, resource timings, and stored HTTP exchanges with clear provenance.
- Open a stored response from Activity, API Lab, Tools, or Findings and run Quick response review for headers, cookie flags, caching, and CORS. You can also review up to 20 selected responses. Passive review sends no requests.
- Save a review result with explicit, encrypted evidence. See the originating exchange, identity, and rule before saving. Activity and retained evidence label bounded previews.
- Find common actions in the command palette with /map, /review, and /finding.

# ESuite 1.0.5

- ESuite opens directly to Browser. Enter an HTTPS address or search with DuckDuckGo from one field. Back, forward, reload and stop controls sit above the live page.
- Developer tools inspect the current page, its document outline, cookie names and supported flags, storage keys, console output and recent same-origin request metadata. Refer to Activity for saved API exchanges.
- Saved requests and observations are available by site without project setup. Open an HTTPS site in API Lab or use Open in API Lab from Browser.
- Settings includes system, light and dark appearance, an animation preference, browsing-data controls, version, WebView information and credits.
- The app uses its own WebView profile on providers with and without multi-profile support. The encrypted saved-data format stays compatible with 1.0.4.

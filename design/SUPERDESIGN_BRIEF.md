# ESuite — Superdesign handoff brief

Status: prepared locally; not sent to Superdesign because no usable connection was returned by plugin discovery.

Design a native Android web/API security workbench for unrooted phones. Product name: **ESuite**. Brand line: **Inspect. Intercept. Investigate.**

Use midnight navy #071019, raised panels #101C29, cyan #5BE0D6, amber #FFB86B, white #E7EEF6 and muted blue-gray #92A5B8. Develop an angular E monogram, practical code editors and clear tool states. Avoid hacker stock photos, matrix text, unnecessary gradients and decorative locks.

Required portrait screens: workspace dashboard; testing browser with touch-selected element; cookie inspector with HttpOnly/Secure/SameSite; searchable traffic list; request/response detail; Repeater-style editor; two-identity comparison; parameter runner; local decoder; findings evidence and redacted export; selected-app capture setup.

Bottom navigation: Home, Browser, Traffic, API Lab, Findings. Put additional tools in the workspace toolkit. Optimize one-handed use, large editors, a soft keyboard, TalkBack labels, 48 dp controls and landscape comparison. Use target, identity and capture-context indicators consistently.

All content must use reserved `.test` hosts, synthetic cookies and example accounts. Distinguish fixture mode, active capture, metadata-only traffic and unsupported decryption. Do not label findings verified without evidence. Do not promise rootless pinning bypass or full Burp equivalence.

Deliver editable screen designs and state variants aligned with `docs/UI_SPEC.md`. The existing local prototype is the behavioral reference, not a mandate to render desktop framing inside the phone.
